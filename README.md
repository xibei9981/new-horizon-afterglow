# 余烬航线 · New Horizon Afterglow

New Horizon 的非官方社区续篇，包含原模组与 **16 张续篇战役地图**。目标版本 **Mindustry 160.4**；Release 提供安卓与电脑通用 JAR。

## 游戏内安装

进入 **模组 → 导入模组 → 从 GitHub 导入**，填写：

```text
xibei9981/new-horizon-afterglow
```

下载后按提示重启。安装前导出游戏数据，移除旧版 New Horizon / 余烬航线以避免重复安装。已有地图存档保留原布局，需要重新开始该关才能使用新布局；已研究科技保留。

## 下载与源码

- [最新发布](https://github.com/xibei9981/new-horizon-afterglow/releases/latest)：选择 `dexed-NewHorizon-Afterglow-0.5.0-Android160.4.jar`，不要解压。
- 同版本完整可编译源码为 `NewHorizon-Afterglow-0.5.0-source.zip`，包含上游源码、修改、16 张地图和构建检查工具。
- 仓库同样提供完整源码；[玩法说明](CAMPAIGN.md)、[验证范围](campaign-tools/VALIDATION.md)。

## 0.5.0 内容

- **赤峡闸口**：红色峡谷、地面部队分流开关、72 波，周期双路与重装突击。
- **白海矿驿**：盐湖阶梯矿坑，真实开采与运输 12 批货物，同时守住至少 48 波。
- **三相遗城**：接管三座能源庭院，持续供电同步，再攻克北部主城。
- 科技随前 12 关推进分阶段开放；第 12 关后全部可研究科技的战役门槛满足，最后四关可以发挥完整体系。仍需研究前置和材料，费用为原来的 20%。
- 修正工业设备开放顺序及弥丹莎基础化工研究入口，按当关科技核对建造材料、必要耗材、至少一种炮塔弹药和单位生产配方。

## 验证范围

本版 16 关引擎机制检查、逐关资源依赖检查和新三关 macOS 桌面客户端加载通过。安卓 D8 编译、全部 1637 个原始类定义与包完整性校验通过。

**尚未完成安卓真机、Windows 原生启动与 16 关人类完整通关验证。** 资源依赖通过不等于产量、电力和战斗难度已全面平衡。旧版波次主要围绕预置防线、物资与阶段援军设置，不能声称已经按每关科技完成实战校准。GitHub 导入用于绕过本地文件选择器，不代表已排除所有安卓运行问题。
